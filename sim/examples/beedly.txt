# Central Beedly (replaces the Luna dog) - run by `make sim-test`:
#   sim.exe --headless --script sim/examples/beedly.txt --frames sim/build/out/beedly/frames ...
#   python sim/tools/check_beedly.py --frames sim/build/out/beedly/frames --script sim/examples/beedly.txt
# `#@beedly <from>..<to> <tag>` lines are the checker's expectations: every dumped frame in that
# window (absolute virtual ms) must show a frame of that Aseprite tag in the slot, with the
# configured frame time, and nothing in the rows around the slot. Times are absolute (`at`).
#
# Matrix positions (alphred_kb ALPH-WIN layer): 24 = LSHIFT, 36 = LALT, 37 = LGUI, 38 = LCTRL
# (plain &kp keys on the left half, so no hold-tap timing is involved).
# Precedence under test: Gui (Idle) > Alt > Ctrl > Shift > Caps Lock > WPM (Idle/Walk/Sprint).

# ---- boot: WPM 0 -> Idle
at 600 expect wpm == 0
# LVGL heap in use after boot; checked again at the end: the modifier / Caps Lock / WPM switches
# reuse the one Beedly object, so nothing is allocated or leaked (update both numbers together
# if a screen layout change moves the boot value)
at 1500 expect heap == 2480
#@beedly 800..4800 idle
at 4000 screenshot sim/build/out/beedly/idle.png
